How to install TLD RevaMP

TLD RevaMP is a mod for the beta branch of The Long Drive on Steam. It works on Windows, and on Linux and Steam Deck through Proton. The mod loader (BepInEx) comes in the same zip, so there's nothing else to download.

Before you start

  • Switch the game to the beta branch: Steam → right-click The Long Drive → Properties → Betas → beta. RevaMP doesn't run on the normal public version.
  • Back up your saves. Windows: Documents\TheLongDrive\Saves. Linux and Steam Deck: ~/.local/share/Steam/steamapps/compatdata/1017180/pfx/drive_c/users/steamuser/Documents/TheLongDrive/Saves.
  • Remove any other mod loader from the game folder first (an old TLDLoader or ModLoader install).

Windows

  1. Download TLD-RevaMP-<version>.zip from the latest release.
  2. Steam → right-click The Long Drive → Manage → Browse local files. That opens the folder with TheLongDrive.exe.
  3. Copy everything from the zip into that folder. winhttp.dll has to end up next to TheLongDrive.exe.
  4. Start the game. The overlay in the top-left corner shows "TLD Revamp" and the version number when the mod has loaded.

Linux and Steam Deck

Do the same steps as on Windows (on Steam Deck, in Desktop Mode), then add this launch option under Steam → The Long Drive → Properties → General → Launch options:

WINEDLLOVERRIDES="winhttp=n,b" %command%

Without it, Proton ignores the mod loader and the game starts without RevaMP.

Updating

Close the game and copy the new zip's files over the old ones, replacing them. Your saves and settings stay. Everyone you play with needs to update too, because players on different versions can't join each other.

Removing it

Delete winhttp.dll, doorstop_config.ini, .doorstop_version, changelog.txt and the BepInEx folder from the game folder. On Linux, also clear the launch option.

Keys

F11 opens the multiplayer menu, Page Up turns the performance overlay on or off, and Page Down saves a bug report. None of them clash with the game's own keys. You can change them in BepInEx\config\tldrevamp.core.cfg, section [Keys].
