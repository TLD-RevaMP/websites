TLD RevaMP

A mod for the beta branch of The Long Drive. It does two things: it fixes a lot of the beta's performance problems, and it throws out the beta's multiplayer and replaces it with one that lets you drive anywhere on the map with your friends.

Made by Normal99 and YujiroX2. Free, GPL-3.0, source on GitHub.

Download the latest release 0.69.0, released 17 Oct 2026 (changelog)

New in 0.69.0

  • Hosts can see and manage players who have left the game.
  • The host now checks hits on cars, creatures and items.
  • Players on different RevaMP versions can't join each other anymore, and the game tells you why. So everyone has to update.

What's in it

Performance

The beta does a lot of the same work over and over, and builds big chunks of the world in a single frame. RevaMP cuts the repeated work, moves terrain and road generation to worker threads, and spreads the rest out over several frames. With 16 parked cars in view we went from about 52 to 72 FPS on our test machine, and the worst hitch while driving was cut in half. Full numbers are further down.

It also fixes bugs in cars, items and saves along the way.

Multiplayer

This isn't the beta's multiplayer with patches on top; it's a separate system. Each player's game simulates the cars, items and creatures near that player, so nobody has to stay close to the host.

What's shared between players:

Players
On foot, seated, driving or riding along, with footsteps and other sounds. You can stand in a moving bus or on top of a car.
Cars
Driving, crashes, damage, parts falling off, fuel and fluids.
Items and doors
Picking up, throwing and dropping loose items; building doors and gates.
Creatures and guns
Hunting, attacks, shots, deaths and bodies; bullet holes and explosions.
World
Sandstorms, tumbleweeds and the radio.
Chat and voice
Text chat on Enter. Proximity voice out to 60 m on the game's Voice chat key (K if it isn't bound). Mute, and kick for the host.

Install

You need your own copy of The Long Drive on Steam, on Windows or Linux with Proton (Steam Deck works). The release comes with BepInEx, the mod loader, so you don't need to get that separately.

  1. In Steam, right-click The Long Drive, go to Properties → Betas and pick beta. Let it finish updating.
  2. Close the game and copy Documents\TheLongDrive\Saves somewhere safe.
  3. Grab the latest release and either run the installer or extract the zip by hand (both below).

With the installer

Windows: download install.ps1, right-click it and choose Run with PowerShell.
Linux or Steam Deck: download install.sh and run bash install.sh in a terminal (Desktop Mode on the Deck).
Pick Install or update and follow the prompts. On Linux it sets the Proton launch option for you if it finds the game's Proton prefix; if it doesn't, it tells you what to add.

By hand

Extract the zip into the folder with TheLongDrive.exe in it (Steam: right-click the game, Manage → Browse local files). INSTALL.txt in the zip has the same steps.

On Linux, also set the game's launch options (Properties → General → Launch Options) to:

WINEDLLOVERRIDES="winhttp=n,b" %command%

Repair or uninstall

Run the installer again and pick Repair or Uninstall. If you installed by hand, extract the same zip again to repair it, or delete winhttp.dll, doorstop_config.ini, .doorstop_version, changelog.txt and the BepInEx folder to remove it. Copy out any settings or reports you want to keep first.

Playing together

Everyone needs the same RevaMP version.

  1. The host starts or loads a world, opens Multiplayer (from the menu, or F11 in game) and picks Host. Setting a password is optional.
  2. Everyone else opens the same menu, picks the host from their Steam friends and hits Join.

It goes through Steam's relay, so there's no port forwarding. The world and the save live on the host's machine; joining someone doesn't touch your own saves.

Questions

Does it work on the normal (non-beta) game?

No, beta only. The normal game has different world generation, saves and multiplayer code underneath.

What keys does it add?

F11 opens Multiplayer, Page Up toggles the performance overlay and Page Down saves a bug report. You can change them in BepInEx\config\tldrevamp.core.cfg. Voice uses the game's own Voice chat key (K if unbound).

What happens to my saves when I join someone?

Nothing. You play in the host's world and your own saves are left alone.

How do I get rid of it?

See Repair or uninstall above.

Found a bug?

Press Page Down when it happens. That saves a report zip. Then open an issue on GitHub, attach the zip and tell us your game branch, RevaMP version, what you were doing, what you expected and what happened instead. For multiplayer bugs, say whether you were hosting or joining and how to make it happen again.
