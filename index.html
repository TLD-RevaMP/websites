Features

What it does

Runs better

Reduces work the game repeats, spreads out world generation, and fixes bugs in cars, items and saves. Less time spent on repeated work means more time for the road.

Real multiplayer

A multiplayer system built from scratch replaces the beta’s own multiplayer. Share players, vehicles, loose items and world interactions, with text chat and proximity voice.

Go anywhere

Players can be anywhere on the map. Each machine simulates the cars, items and creatures near its own player, so nobody has to stay close to the host.

Multiplayer

What syncs

  • PlayersOn foot, seated, driving or riding as passengers, with footsteps and other player sounds. Stand in a moving bus or on a car.
  • VehiclesDriving, crashes, damage, parts coming off, fuel and fluids.
  • Items & doorsCarry, throw and drop loose items; share building doors and gates.
  • Creatures & combatHunting, attacks, shots, deaths and bodies; guns, bullet holes and explosions.
  • World events & radioSandstorms, tumbleweeds and the radio.
  • Chat & voiceText chat with Enter; proximity voice within 60 m using the game's Voice chat key (K if unbound). Mute, and kick for the host.

Play together

Everyone needs the same RevaMP version.

  1. Host: start or load a world, open Multiplayer from the game’s menu or press F11 in game, then choose Host. A password is optional.
  2. Join: select the Steam friend who is hosting in the Multiplayer menu and choose Join.

Steam relay handles the connection, so no port forwarding is needed. The host’s machine owns the world and save; joining loads that world and leaves your own saves alone.

Before you start

Requirements

The game, beta branch

Your own copy of The Long Drive on Steam, switched to the beta branch.

Windows, or Linux with Proton including Steam Deck.

Same version

Everyone in a multiplayer session needs the same RevaMP version.

Get started

Install

BepInEx, the mod loader, is included in the release.

  1. Switch to the beta branch. In Steam, right-click The Long Drive → Properties → Betas → beta. Let the update finish.
  2. Close the game and back up your saves. Copy Documents\TheLongDrive\Saves somewhere safe before installing or updating.
  3. Get the latest release. Use its installer if included, or download the zip and follow INSTALL.txt inside.

Installer

On Windows, download install.ps1, right-click it and choose Run with PowerShell. On Linux or Steam Deck, download install.sh and run bash install.sh in a terminal (Desktop Mode on Steam Deck). Choose Install or update and follow the prompts.

Manual zip

Extract into the game folder containing TheLongDrive.exe. Find it through Steam: right-click the game → Manage → Browse local files.

Linux / Proton

For a manual install, add this under Steam → Properties → General → Launch Options:

WINEDLLOVERRIDES="winhttp=n,b" %command%

The installer sets the Proton override when the game’s Proton prefix exists; otherwise, follow its launch-option instructions.

Repair or uninstall: run the installer again and select Repair or Uninstall; for a manual install, re-extract the same zip to repair, or remove winhttp.dll, doorstop_config.ini, .doorstop_version, changelog.txt and the BepInEx folder to uninstall. Keep any settings or reports you want first.

FAQ

Questions

Does it work on the normal (non-beta) game?

No. RevaMP is built for the beta only. The normal game uses different world generation, save and multiplayer code.

How do we play together?

One player starts or loads a world and chooses Host in the Multiplayer menu (F11 in game). Steam friends select that player and choose Join. A password is optional, and no port forwarding is needed. Everyone needs the same RevaMP version; a mismatch is refused with an explanation. See Play together.

What happens to my saves when I join someone?

The host's machine owns the world and its save. Joining loads that world and leaves your own saves alone.

Which keys does it add?

F11 opens Multiplayer, Page Up shows the performance overlay, and Page Down saves a bug report. These keys can be changed in BepInEx\config\tldrevamp.core.cfg. To talk, hold the game's Voice chat key (K if unbound).

Linux or Steam Deck?

Use Proton. For a manual install, set Steam → Properties → General → Launch Options to:

WINEDLLOVERRIDES="winhttp=n,b" %command%

See Install for the installer and manual steps.

Something went wrong. What should I send?

Press Page Down when it happens and again after playing. Attach the report zip to a RevaMP issue and describe the problem. See Report a problem.

How do I remove it?

Run the installer and choose Uninstall, or remove the loader files from a manual installation. See Install for the file list.

Help us fix it

Report a problem

Open a GitHub issue ↗ describing the bug and when it happened. Include your game branch and RevaMP version, what you were doing, what you expected, and what happened instead. For multiplayer, say whether you were hosting or joining and how to reproduce it.

Press Page Down when the problem happens to save a report zip, then attach it to your issue.
