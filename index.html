TLD RevaMP

Performance fixes and rebuilt multiplayer for The Long Drive’s beta branch.

Download ↓ Source ↗

Requires your own copy of The Long Drive on Steam.

What it does

01

Runs better

Reduces work the game repeats, spreads out world generation, and fixes bugs in cars, items and saves. Less time spent on repeated work means more time for the road.

02

Real multiplayer

A multiplayer system built from scratch replaces the beta’s own multiplayer. Share players, vehicles, loose items and world interactions, with text chat and proximity voice. Players can explore anywhere on the map.

How it was measured

One machine, the same beta game, world (seed 20260924), settings and scripted runs: the mod loader alone, then RevaMP 0.69.0 added. Three alternating runs each; values are medians, with ranges in brackets. 1280 × 720, Ultra, vsync off, no frame cap. Frame times were recorded on the game’s main loop, on the processor side.

Install

Windows or Linux with Proton, including Steam Deck. BepInEx, the mod loader, is included in the release zip.

  1. Switch to the beta branch. In Steam, right-click The Long Drive → Properties → Betas → beta. Let the update finish.
  2. Close the game and back up your saves. Copy Documents\TheLongDrive\Saves somewhere safe before installing or updating.
  3. Get the latest release. Use its installer if included, or download the zip and follow INSTALL.txt inside.

Installer

On Windows, download install.ps1, right-click it and choose Run with PowerShell. On Linux or Steam Deck, download install.sh and run bash install.sh in a terminal (Desktop Mode on Steam Deck). Choose Install or update and follow the prompts.

Manual zip

Extract into the game folder containing TheLongDrive.exe. Find it through Steam: right-click the game → Manage → Browse local files.

Linux / Proton

For a manual install, add this under Steam → Properties → General → Launch Options:

WINEDLLOVERRIDES="winhttp=n,b" %command%

The installer sets the Proton override when the game’s Proton prefix exists; otherwise, follow its launch-option instructions.

Repair or uninstall: run the installer again and select Repair or Uninstall; for a manual install, re-extract the same zip to repair, or remove winhttp.dll, doorstop_config.ini, .doorstop_version, changelog.txt and the BepInEx folder to uninstall. Keep any settings or reports you want first.

Play together

Everyone needs the same RevaMP version.

  1. Host: start or load a world, open Multiplayer from the game’s menu or press F11 in game, then choose Host. A password is optional.
  2. Join: select the Steam friend who is hosting in the Multiplayer menu and choose Join.

Steam relay handles the connection, so no port forwarding is needed. The host’s machine owns the world and save; joining loads that world and leaves your own saves alone.

Report a problem

Open a GitHub issue ↗ describing the bug and when it happened. Include your game branch and RevaMP version, what you were doing, what you expected, and what happened instead. For multiplayer, say whether you were hosting or joining and how to reproduce it.

Keep report zips and marks out of public issues. The developers ask for those files privately.
