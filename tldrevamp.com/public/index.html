The Long Drive overhaul mod

TLD RevaMP (The Long Drive Revamp) is a free overhaul for the beta branch of The Long Drive. The game runs faster, multiplayer lets you drive anywhere on the map together, and other mods can build on it.

What it does

Performance

Less repeated work, and world generation moved off the main thread. 16 parked cars: 52 → 72 FPS. Worst hitch while driving: halved.

Multiplayer

Each player's game runs what's near them, so nobody has to stay near the host. Cars, items, doors, creatures, guns, sandstorms and the radio are shared, with text chat and proximity voice (K). Over Steam, no port forwarding.

Mods

A base for other mods. The in-game mod browser (Settings → Revamp → Mods) installs approved mods, and a multiplayer API lets mod makers share their mod's objects with everyone in a session. More is on the way.

Fixes

Bug fixes for cars, items and saves, in single player too.

Install

  1. Steam: right-click The Long Drive → Properties → Betas → beta.
  2. Back up Documents\TheLongDrive\Saves.
  3. Extract the zip into the folder with TheLongDrive.exe (Steam → Manage → Browse local files). The mod loader (BepInEx) is included.
  4. Host or join with F11. Everyone needs the same version.
WINEDLLOVERRIDES="winhttp=n,b" %command%

Launch option for Linux and Steam Deck. More detail, updating and removing it: install guide.

Playing together

The host loads a world, presses F11 and picks Host. Friends press F11, pick the host and Join. No port forwarding; your own saves aren't touched. See the guide to The Long Drive multiplayer.

Found a bug?

Press Page Down when it happens to save a report zip, then open an issue saying what happened. Don't attach the zip, since issues are public; keep it on your PC and we'll ask for it privately if we need it.
