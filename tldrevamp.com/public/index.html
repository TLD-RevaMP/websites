The Long Drive multiplayer mod

TLD RevaMP (The Long Drive Revamp) is a free mod for the beta branch of The Long Drive. The game runs faster, and its multiplayer is replaced with one where you can drive anywhere on the map together.

Download 0.69.0, 17 Oct 2026 (changelog)

What it does

Performance. Less repeated work, and world generation moved off the main thread. 16 parked cars: 52 → 72 FPS. Worst hitch while driving: halved. Plus bug fixes for cars, items and saves.

Multiplayer. Players, cars, items, doors, creatures, guns, sandstorms and the radio are shared. Each player's game runs what's near them, so nobody has to stay near the host. Text chat, and proximity voice on the game's Voice chat key (K if unbound).

Install

Needs The Long Drive on Steam, on Windows or Linux/Steam Deck with Proton. The mod loader (BepInEx) is included.

  1. Steam: right-click The Long Drive → Properties → Betas → beta.
  2. Back up Documents\TheLongDrive\Saves.
  3. Download the zip from the latest release and extract everything into the folder with TheLongDrive.exe (Steam → Manage → Browse local files).

On Linux or Steam Deck, also set this launch option:

WINEDLLOVERRIDES="winhttp=n,b" %command%

More detail, updating and removing it: install guide.

Playing together

Everyone needs the same version. The host loads a world, presses F11 and picks Host. Friends press F11, pick the host and Join. No port forwarding; your own saves aren't touched. See the guide to The Long Drive multiplayer.
